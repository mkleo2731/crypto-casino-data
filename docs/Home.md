# Crypto Casino Data

Aggregated dataset and analysis tools for cryptocurrency casino platforms, covering house edges, supported coins, provably fair status, and regional availability.

## Overview

This project maintains a structured dataset of cryptocurrency casino and sportsbook platforms. The data covers operational details, supported cryptocurrencies, game fairness, geographic availability, and bonus structures.

### What Is Included

- **Platform profiles** — Name, launch year, license jurisdiction, supported cryptocurrencies
- **House edge data** — Documented house edges for major game categories (slots, blackjack, roulette, dice)
- **Provably fair status** — Whether the platform supports cryptographic fairness verification
- **Regional availability** — Which platforms accept players from specific countries
- **Payment methods** — Deposit/withdrawal options including fiat on-ramps

## Use Cases

This dataset supports several types of analysis:

- **Platform comparison** — Compare house edges, supported coins, and bonus offers
- **Regional research** — Identify which platforms serve specific markets (Nigeria, Brazil, India, Vietnam)
- **Fairness auditing** — Cross-reference provably fair claims with [provably-fair-verifier](https://github.com/mkleo2731/provably-fair-verifier)
- **Market analysis** — Track crypto adoption trends across the gambling industry
