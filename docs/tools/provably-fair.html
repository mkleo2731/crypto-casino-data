Provably Fair Verifier

Verify that a crypto casino game outcome was fair by checking the cryptographic hash. This tool runs entirely in your browser — no data is sent to any server.

How Provably Fair Works

  1. 1. Before each round, the casino commits to a server seed hash (the hash of the actual server seed).
  2. 2. You provide or accept a client seed and the nonce increments each round.
  3. 3. The game result is derived from HMAC-SHA256(serverSeed, clientSeed:nonce).
  4. 4. After the round, the casino reveals the server seed. You can verify: SHA256(serverSeed) === committedHash.
